# The 50-Style Semantic Trigger Map

This manual maps storytelling situations, emotional tones, script trigger keywords, polarity, and asset requirements across all 50 active procedural styles.

### Cluster 1: Power, Manipulation, Games & Conflict (1–9)
#### 1. `shadow-puppet` · Shadow Puppetry · 皮影戏
* **Trigger Situation / Metaphor:** Behind-the-scenes rulers, oligarchs, proxy wars, lobbying, puppet states.
* **Core Emotion:** Sinister manipulation, hidden strings.
* **Script Trigger Words & Phrases:** *pulled the strings, behind the curtain, puppet, aristocrats, shadow government, proxy, handlers, quiet control*.
* **Polarity / Asset Tier:** `dark` | `pure_code`
